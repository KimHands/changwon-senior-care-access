# changwon-senior-care-access

**행정구역은 '동'인데 의료 접근성은 읍면 수준인 곳 — 창원시 경로당 873개 지점 기반 1차의료 접근성 분석과 방문건강관리 현장 확인 대상 선정**

2026년 창원시 AI·데이터 활용 공모전(창원시 공고 제2026-1099호) 분석보고서와 수집·정제·분석 스크립트.
팀 "동네 안에 읍면" — 김종건 · 김상현 (순천향대학교 컴퓨터소프트웨어공학과)

## 무엇을 했나

창원시 경로당 각 지점에서 가장 가까운 1차의료기관까지의 거리를 계산해, 행정구역상 '동'이면서 실제 접근성은 읍면 수준인 지점을 추렸다. 행정동 단위 평균으로는 보이지 않는 지점을 기존 보건사업(방문건강관리)의 현장 확인 대상 선정 자료로 쓰는 것이 목적이다.

제출한 보고서: [`05_제출본/`](05_제출본/) (hwpx · pdf, 2026-09-29 제출, A4 18매)

`02_데이터/raw/`는 저장소에 없다. 스크립트가 포털에서 다시 받는다.

## 재현

검증 환경: Python 3.14, 패키지 버전은 `03_분석/requirements.txt`에 고정. 01~07·10번은 표준 라이브러리만 쓴다.

```bash
python3 -m venv .venv && .venv/bin/pip install -r 03_분석/requirements.txt
cp .env.example .env    # VWORLD_KEY 를 채운다 (아래 참고)

.venv/bin/python 03_분석/00_수집_역대수상작_요약서.py       # 역대 수상작 요약서 (창원시 데이터포털)
python3 03_분석/01_수집_창원데이터포털_카탈로그.py
python3 03_분석/02_집계_도메인_판정.py
python3 03_분석/03_실측_후보데이터_프로파일.py            # 분석 데이터 원본 수집
python3 03_분석/04_정제_지오코딩.py                      # 주소 → 좌표 (VWORLD_KEY 필요)
python3 03_분석/05_실측_인구데이터.py --month 202606      # 제출본 기준월
python3 03_분석/07_수집_보건기관.py --file-id FILE_000000003692397   # 제출본 첨부파일, 좌표화 포함
python3 03_분석/06_분석_접근성.py                        # 07번 산출물을 읽는다 — 07 다음에 실행
.venv/bin/python 03_분석/08_분석_군집.py
.venv/bin/python 03_분석/09_시각화_지도.py
python3 03_분석/10_검증_숫자대조.py --report 04_보고서/제출본_분석보고서_본문.md    # 보고서 수치 대조
python3 03_분석/13_검증_표절대조.py --report 04_보고서/제출본_분석보고서_본문.md    # 역대 수상작과 대조
```

11·12·15·17번은 보고서 조판·매수 측정 도구다. 각 스크립트 첫머리 주석에 입력·출력·재현 명령이 있다.

**VWorld 인증키:** [vworld.kr](https://www.vworld.kr) › 오픈API › 인증키 발급. 서비스유형 `기타`, 서비스URL `http://localhost`, 활용API에 `지오코더`를 체크한다.

### 제출 당시 결과와 같은가

위 명령은 **최신 원본으로 다시 분석하는 경로**다. 제출 당시 결과와 같은 값을 보장하지는 않는다.

| 단계 | 제출 당시 입력 고정 | 비고 |
|---|---|---|
| 05 인구 | 됨 (`--month 202606`) | |
| 07 보건기관 | 됨 (`--file-id`) | |
| 03 경로당·의료기관·식사배달 | **안 됨** | 포털에 올라온 최신 첨부파일을 받는다. 제출 당시 파일명·기준시점은 `02_데이터/clean/후보데이터_프로파일.json`에 있다 |
| 04·07 좌표 | **안 됨** | 제출 당시 좌표(지오코딩 캐시)는 공개본에 없고, VWorld의 현재 응답을 받는다 |

`10`번의 대조 결과(`03_분석/숫자대조표.md`)는 제출 당시 데이터로 만든 것이다. 제출 당시 좌표가 필요하면 아래 「공개본에서 뺀 것」을 참고한다.

`04`번은 네트워크 오류가 난 주소도 캐시에 `ERROR:…` 상태로 남기고 정상 종료한다. `02_데이터/clean/지오코딩_실패목록.csv`의 실패사유가 `ERROR:`로 시작하는 행이 있을 때만 `04 --refresh`로 다시 조회한다(`NOT_FOUND`는 주소 자체가 검색되지 않은 것이라 다시 조회해도 같다). `--refresh`는 보건기관 주소까지 든 캐시 전체를 새로 만들므로, 그 뒤 `07`부터 다시 실행한다.

## 공개본에서 뺀 것

| 무엇 | 왜 | 다시 만드는 법 |
|---|---|---|
| 역대 수상작 요약서 원문 텍스트 | 다른 팀의 저작물이다 | `00`번 |
| 좌표 숫자가 든 표 (`지오코딩_캐시`, `경로당·의료기관·보건기관·식사배달기관_좌표`, `경로당_접근성`, `경로당_군집`) | VWorld 지오코더 결과의 재배포 조건을 확인하지 못했다 | `04` → `07` → `06` → `08` (VWORLD_KEY 필요) |

다시 만든 파일은 `.gitignore`에 들어 있어 커밋되지 않는다. 보고서에는 "지오코딩 캐시로 인증키 없이 같은 좌표가 나온다"고 적었으나, 그 캐시는 위 이유로 공개본에 없다. 공개 검증 기간에 요청하면 제공한다.

지도 그림(`04_보고서/그림/`, 제출본에 실린 그림 1~3)은 위 좌표로 그린 것이다. 좌표 숫자는 공개하지 않고 지도로만 표출한다.
